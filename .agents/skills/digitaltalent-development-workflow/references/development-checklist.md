# 开发前检查清单

用途：每个开发任务开始前，根据任务等级勾选适用项目。轻量任务不必机械执行完整清单；安全、授权和 Git 保护要求不得省略。

## A. 任务边界

- [ ] 项目根目录确认为 `D:\AI\DigiTalent_AI`
- [ ] 已明确任务目标、交付物、验收标准及禁止事项
- [ ] 已确认本次执行等级：轻量 / 标准 / 完整
- [ ] 已遵守 `AGENTS.md` 中与本次任务相关的约定
- [ ] 已明确本次不做的事项
- [ ] 前置任务（如有）已按实际证据核验

## B. 上下文与环境（按需）

- [ ] 已复用当前对话、任务资料和可信的既有检查结果
- [ ] 只读取与当前任务直接相关的文件
- [ ] 仅检查本次会使用的环境和工具
- [ ] 若执行 Python，已核验 Conda `feiyu` 环境；本次可信核验结果可复用时不重复检查
- [ ] 若涉及数据库，已核验目标 MySQL 实例及测试库隔离情况
- [ ] 若涉及模型服务或前端，才检查对应运行环境
- [ ] 未对无关服务、目录或设备进行例行扫描

## C. Git 工作区保护（开发前必须）

- [ ] 已执行并记录 `git status --short`
- [ ] 已执行并记录 `git diff --stat`
- [ ] 已识别开发前已有未提交修改及未跟踪文件
- [ ] 确认不会覆盖用户已有修改
- [ ] 不执行 `git add` / `git commit` / `git push`（除非用户明确授权）
- [ ] 不执行 `git checkout -- .` / `git reset --hard` / `git clean`

## D. 代码现状与文件职责（按需）

- [ ] 已找到相关现有实现，确认是否复用
- [ ] 已确认本次修改文件及明确不修改的文件
- [ ] 已检查直接调用方、注册入口和关联测试
- [ ] 标准/完整任务已参考 `file-responsibility-guide.md`
- [ ] 未为了解背景扫描整个项目

## E. 技术方案与依赖（按需）

- [ ] 方案符合当前已确认技术选型
- [ ] 未引入未经确认的依赖、框架或目录约定
- [ ] 重大技术或安全边界不确定性已向用户确认
- [ ] 新增依赖已获授权，并检查兼容性及现有清单
- [ ] 未在代码或配置中写入真实密码、Token、API Key

## F. 数据库安全（涉及数据库时必做）

- [ ] 目标数据库为 MySQL
- [ ] 已明确数据库实例、目标数据库名称及用途
- [ ] 测试使用独立 MySQL 测试数据库，与业务库隔离
- [ ] 已确认连接配置来源（只记录配置项名称，不记录秘密值）
- [ ] 需要执行 DDL/DML、初始化、清理或结构变更时，已取得明确授权
- [ ] 未将未知性质的数据库视为测试数据库
- [ ] 不执行未经授权的建库、删库、建表、改表、删表或数据清理
