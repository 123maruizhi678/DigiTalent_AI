# 验收报告模板

使用说明：

- 每项开发任务输出一份；所有内容必须来自真实命令输出或可核验事实。
- 保存路径由当前任务提示词指定；未授权时直接在对话中输出，不自行创建项目文档。
- 不适用的章节标记“不适用”，不得为填满模板而编造内容。
