# 测试检查清单

用途：按任务风险选择测试类型并留下可核查证据。不得用一种测试通过冒充另一种测试通过。

## 1. 测试环境与命令规范

所有 Python 测试、静态检查、格式检查和依赖管理命令通过 Conda `feiyu` 环境执行。

```powershell
conda run -n feiyu python -m pytest
conda run -n feiyu python -m ruff check .
conda run -n feiyu python -m ruff format --check .
```

如 `conda` 不在 PATH，使用项目已确认的 Conda 绝对路径调用 `run -n feiyu`。不得直接调用系统 Python 或裸 `pytest`、`ruff`。

记录实际使用的：
- 命令全文；
- 执行目录；
- Python/pytest 版本（可复用本次有效环境核验结果）；
- 退出码；
- 通过、失败、跳过和未执行数量。

## 2. 测试类型与证据

| 类型 | 适用场景 | 必备证据 | 不能证明什么 |
|---|---|---|---|
| 单元测试 | 纯函数、类、模型规则 | 用例、数量、结果、退出码 | 不能证明真实外部依赖可用 |
| Mock 测试 | 外部服务、HTTP 客户端等 | Mock 边界、被替代行为 | 不能证明真实服务可用 |
| API 测试 | 路由、状态码、响应结构 | 路径、方法、断言、结果 | 不能单独证明真实数据库行为 |
| MySQL 测试 | ORM、会话、事务、约束、仓储逻辑 | 隔离测试库名称/性质、MySQL 版本、命令和结果 | 不能证明生产网络及生产配置可用 |
| 静态检查 | 语法、常见缺陷 | 工具、版本、目标范围、告警数 | 不能证明业务逻辑正确 |
| 格式检查 | 代码格式 | 工具、目标范围、结果 | 不能证明逻辑正确 |
| 类型检查 | 类型一致性（项目已配置时） | 工具、版本、结果 | 不能证明运行时行为 |
| 前端构建/测试 | 前端改动 | 命令、结果、产物 | 不能证明真实浏览器体验 |
| 真实环境验证 | 启动、联调、外部服务 | 地址/步骤/脱敏日志或截图 | 不能证明生产环境可用 |

## 3. MySQL 测试规范

项目关系型数据库统一使用 MySQL。数据库相关测试必须使用独立 MySQL 测试数据库。

1. 测试数据库必须与开发数据库、生产数据库严格隔离。
2. 记录目标 MySQL 实例、版本、测试库名称及连接配置来源；不得记录密码或完整连接串。
3. 测试所需结构通过人工维护、已审核的 SQL 文件准备。
4. 不得自动创建、删除或重建数据库和表。
5. 未经用户明确授权，不执行 DDL、DML、清理或重置操作。
6. 不存在已确认的隔离测试库时，不得将业务库当作测试库；报告未执行原因并等待授权。
7. 不得以 Mock 测试代替真实 MySQL 测试，也不得以 MySQL 测试通过冒充 API 或业务验收全部通过。

## 4. 按任务类型选择测试

| 任务类型 | 建议测试 |
|---|---|
| 纯文档/配置说明 | 相关文件检查、引用/格式检查；代码测试通常不适用 |
| 纯函数或业务逻辑 | 相关单元测试 + 静态检查 |
| ORM 模型 | 模型单元测试 + 隔离 MySQL 测试（涉及真实映射/约束时）+ 静态检查 |
| API | API 测试 + 关联单元测试；涉及数据库时增加 MySQL 测试 |
| 数据库连接/会话 | 单元测试 + 授权的隔离 MySQL 集成测试 |
| 安全/权限 | 未认证、越权、输入校验及相关 API/单元测试 |
| 前端 | 前端测试 + 构建 + 必要页面验证 |
| 公共基础组件 | 直接测试 + 受影响下游模块回归 |

根据实际风险扩大或缩小测试范围，并说明理由。

## 6. 失败处理

- 保留原始错误输出及关键堆栈；
- 记录文件路径和行号；
- 区分代码、环境、依赖、数据或用例假设问题；
- 修复后重跑失败用例及相关测试；
- 按 `../SKILL.md` §8.1 处理问题：发现时在已有对应记录中及时记录，修复并完成必要验证后直接更新当前结论及任务状态，不以追加修复说明代替原文修订；未验证不得标记为已解决。
- 原始失败输出、命令及重试结果按执行轮次保留为证据；当前验收结论反映最新有效结果，仍未通过或未执行的要求继续列明，不得篡改历史证据。

## 7. 未执行项说明

每项未执行测试必须记录：

- 测试类型；
- 未执行原因（范围、环境、缺少授权、缺少隔离测试库等）；
- 对验收结论的影响；
- 后续所需条件。

存在必须测试未执行时，不得将整体验收标记为“已完成”。
