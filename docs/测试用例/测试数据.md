## 3. 准确性评测用法

三份 JSON 为"标注输入"，配合一个简单的对比脚本（建议 Python）回归：

```python
import json
# 简历解析：拉取 parsed_resumes，与 resume_parse_eval.json 的 expected 逐项比对
# 匹配：调用 /api/resumes/match-lists，比对 passed/score 区间与 reason 关键词
# RAG：调用 /api/knowledge-base/ask，比对 answer 关键词命中 + sources 是否含 expected_source_chunk_ids
```
- 解析：`field_f1 = 命中字段 / 标注字段`，目标 ≥0.99。
- 匹配：`一致率 = 通过判定一致条数 / 总条数`，目标 ≥0.90；并校验 `score` 落在区间、`reason` 含关键词。
- RAG：答案正确率（命中标准来源且要点正确）≥0.95；无据问题须触发拒答（幻觉抑制）。
