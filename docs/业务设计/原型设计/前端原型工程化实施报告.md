# 前端原型工程化实施报告

日期：2026-11-03

## 1. 原型分析与实施计划
已完整读取指定 HTML（含所有 section、样式及尾部脚本），没有扫描其他 docs 文件。
原型共 11 个页面：智能工作台、简历智能筛选、人才画像档案、智能测评、岗位人才匹配、个性化培训、智能问数、企业人才知识库、Agent 编排中心、系统管理、技术架构现状与差距。

原型是纯 HTML/CSS/SVG：只有导航切页、Tab 切换和 chip 点击态脚本；按钮、问答输入、导出等原本没有完整业务行为，也没有真实弹窗或下拉业务逻辑。

视觉基准：242px 深色渐变侧栏；60px 白色顶部栏；背景 #f4f6fb；品牌 #2563eb / #4f46e5；文本 #0f172a / #475569 / #94a3b8；边框 #e7ebf3；14px 卡片圆角；14px 网格间距；主内容 22px 26px 40px；字体 PingFang SC / Microsoft YaHei。原型线性 SVG 图标以 Element Plus 同类图标承接。柱状图和雷达图分别从 CSS、SVG 改为 ECharts；工作流 SVG 连线结构保留。

页面关联：简历查看画像跳转人才档案；Agent 任务调度跳转数字员工；系统管理含用户、角色与权限、审计 Tab；导航以路由驱动，高亮对应当前页面。

实施顺序：原型清单和范围核对 → 视觉规范提取与页面拆分 → 公共布局、路由、Store → 本地交互与图表 → 检查、浏览器验证、报告。

共实现 11 个独立 Vue 页面（10 个平台页面 + 演示登录）。9 个页面来自保留的原型；新增数字员工页和登录页。没有整页 HTML iframe、v-html 或把原型作为正式入口。

## 3. 目录与公共组件
src 下实际使用 api、assets/styles、components/business、components/charts、layouts、router、stores/modules、styles、types、utils、views 目录。不创建空目录。

- MainLayout：侧栏、顶部栏、通知、用户菜单、搜索、内容容器。
- DemoTable：Element Plus 表格、文本筛选、分页、行操作。
- ModuleWorkspace：按模块配置的 Tab、记录筛选、增改删、状态模拟；没有将其宣称为完整的各业务专用表单。
- ActionDialog：通用操作登记、必填校验、取消与保存、本地操作记录。
- OnlineAssessment：五种题型、完整性校验、客观题评分、简答题待人工评阅。
- BusinessChart：ECharts / Vue ECharts，自动尺寸适配。

原型样式单独放 assets/styles/prototype.css；工程样式放 styles/index.css。App.vue 仅挂载 router-view。

## 4. 路由与状态设计
采用 Hash 路由，可在静态托管环境刷新深层地址。集中配置页面懒加载；未知路径回工作台；路由守卫设置标题并保留 requiresAuth 扩展点。当前允许公开演示。

user Store：演示用户、认证占位标记、菜单折叠。
demo Store：跨页面操作登记记录。
workspace Store：按业务分区保存本地示例记录，支持新增、编辑、删除、状态修改。
状态仅存在内存，刷新重置；没有持久保存敏感资料。
filterMenus(allowed) 为菜单权限过滤扩展；不构成真实安全授权。真实认证与权限验证仍需后端。
api/request.ts 仅预留 Axios 实例，页面不调用；未调用 Python、MySQL、Milvus、Ollama、MinerU 等服务。

## 6. 本地交互实现与边界
已实现菜单组展开、侧栏折叠、路由切换、高亮、页内 Tab、导航搜索、表格搜索与分页、岗位/分数/解析状态筛选、筛选重置、用户下拉、通知抽屉、模型信息弹窗、表单基本校验、本地记录增改删、模拟执行与状态更新、五种题型作答和评分。
导出生成带演示标记的 JSON，不伪装为真实 Word/PDF。原型按钮中尚无专用业务编辑流程的操作，打开通用登记弹窗；填写后保存到可见本地操作记录，不执行 AI。

## 7. 尚未实现与人工验收事项
- 工作流画布为静态结构预览，尚未实现拖拽连线、条件编辑和可执行图保存。
- 各业务子功能使用通用本地配置工作区，尚非完整的专用招聘流程、题库编辑器、组织树、权限矩阵、Cron 调度器或运营驾驶舱。
- 上传、批量导入、AI 问答、试运行等只做本地登记/模拟；没有文件解析、真实生成、动态语义检索与后端处理。
- 查询分析是预设演示快照；部分 chip 保留选择态，尚未实现完整多条件业务算法。
- 无真实登录、后端权限、真实通知、真实导出 Word/PDF、持久化和实时监控。
- 保留原型核心视觉规范与布局，但 Element Plus 表格/菜单细节和新增页并非逐像素一致。需人工验收各页视觉、业务字段、标签筛选语义和复杂流程。
